# Maaroud Project Documentation

This folder captures the agreed product, brand, growth, UX, architecture, and scraping decisions for the Maaroud MVP.

## Product in one sentence

**Maaroud is a shopping-discovery platform that helps users find products from Egyptian brands and purchase directly from each brand's own website.**

Maaroud is not a conventional marketplace: it does not own checkout, payments, shipping, returns, or inventory.
